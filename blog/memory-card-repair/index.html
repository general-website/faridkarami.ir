تعمیر مشکلات مموری، کارت حافظه و فلش

اگر فلش، کارت حافظه یا مموری گوشی شما توسط کامپیوتر شناسایی نمی شود، فرمت نمی شود، فایل سیستم آن به صورت RAW نمایش داده می شود یا هنگام فرمت کردن خطا می دهد، لزوما به این معنی نیست که حافظه کاملا خراب شده است.

در بسیاری از مواقع مشکل با چند دستور ساده در ویندوز قابل حل است.

در این راهنما، رایج ترین مشکلات فلش، کارت حافظه و microSD را بررسی می کنیم و مرحله به مرحله روش تعمیر آنها را توضیح می دهیم.

هشدار: بعضی از روش های این مقاله باعث حذف کامل اطلاعات می شوند. اگر فایل های داخل حافظه برای شما مهم هستند، قبل از اجرای دستورات تعمیر، سراغ فرمت و DiskPart نروید و ابتدا اطلاعات را ریکاوری کنید.

1. چرا فلش یا مموری خراب می شود؟

خرابی حافظه می تواند دلایل مختلفی داشته باشد. مهم ترین آنها عبارتند از:

  • خارج کردن فلش یا کارت حافظه هنگام انتقال اطلاعات
  • قطع شدن برق هنگام نوشتن اطلاعات
  • خرابی فایل سیستم
  • استفاده از کارت حافظه بی کیفیت
  • پر شدن کامل حافظه
  • خرابی سلول های حافظه
  • خرابی کنترلر داخلی فلش یا کارت
  • خرابی یا ناسازگاری Card Reader
  • ویروس یا بدافزار
  • استفاده مداوم و سنگین از کارت حافظه
  • ریکاوری اطلاعات با نرم افزارهای تخصصی
  • آسیب فیزیکی یا آب خوردگی
  • استفاده از کارت حافظه تقلبی با ظرفیت غیر واقعی

بنابراین باید ابتدا مشخص کنیم مشکل نرم افزاری است یا سخت افزاری.

2. اولین قدم: آیا ویندوز حافظه را می شناسد؟

فلش یا کارت حافظه را به کامپیوتر وصل کنید.

اگر در This PC نمایش داده می شود، مشکل معمولا ساده تر است.

اما اگر نمایش داده نمی شود، وارد Disk Management شوید.

کلیدهای زیر را فشار دهید:

Win + X

سپس:

Disk Management

را انتخاب کنید.

در این قسمت باید دنبال حافظه خودتان بگردید.

ممکن است حافظه با یکی از این وضعیت ها نمایش داده شود:

  • RAW
  • Unallocated
  • Healthy
  • No Media
  • بدون Drive Letter
  • ظرفیت اشتباه
  • ظرفیت درست ولی بدون پارتیشن

هر کدام از این حالت ها معنی متفاوتی دارد.

3. مشکل RAW چیست؟

اگر فایل سیستم حافظه به صورت RAW نمایش داده شود، یعنی ویندوز نمی تواند فایل سیستم آن را به شکل معمول تشخیص دهد.

برای مثال ممکن است در Disk Management ببینید:

28 GB
RAW
Healthy

در این حالت معمولا اطلاعات قبلی قابل استفاده نیستند.

اگر اطلاعات برایتان مهم نیست، می توانیم پارتیشن را پاک کرده و دوباره بسازیم.

اما اگر اطلاعات مهم هستند، نباید بلافاصله Format کنید.

4. اگر اطلاعات مهم نیست، بهترین روش چیست؟

اگر هیچ فایلی روی فلش یا کارت حافظه برای شما مهم نیست، یکی از بهترین روش ها استفاده از ابزار داخلی Windows یعنی DiskPart است.

برای اجرای آن:

  1. Start را باز کنید.
  2. عبارت cmd را جستجو کنید.
  3. روی Command Prompt راست کلیک کنید.
  4. گزینه Run as administrator را انتخاب کنید.

سپس بنویسید:

diskpart

5. پیدا کردن شماره فلش یا مموری

بعد از ورود به DiskPart دستور زیر را اجرا کنید:

list disk

مثلا ممکن است چنین چیزی ببینید:

Disk ###  Status         Size
--------  -------------  -------
Disk 0    Online          465 GB
Disk 1    Online          447 GB
Disk 2    Online          232 GB
Disk 3    Online           28 GB

در این مثال، کارت حافظه 28GB برابر با Disk 3 است.

بسیار مهم

قبل از انتخاب Disk مطمئن شوید شماره مربوط به فلش یا کارت حافظه است.

مثلا اگر هارد کامپیوتر شما 465GB است:

Disk 0    465 GB

نباید به اشتباه آن را انتخاب کنید.

انتخاب Disk اشتباه و اجرای clean می تواند اطلاعات یک هارد دیگر را از بین ببرد.

6. پاک کردن پارتیشن خراب

اگر مطمئن شدید که Disk 3 کارت حافظه شماست:

select disk 3

باید پیام زیر را ببینید:

Disk 3 is now the selected disk.

حالا:

clean

اگر پیام زیر را دیدید:

DiskPart succeeded in cleaning the disk.

یعنی اطلاعات پارتیشن بندی قبلی پاک شده است.

در این مرحله حافظه عملا بدون پارتیشن است.

7. اگر Create Partition کار نکرد چه کنیم؟

در حالت عادی بعد از clean باید بتوانیم این دستور را اجرا کنیم:

create partition primary

اما ممکن است با خطایی مانند این مواجه شوید:

No usable free extent could be found.

یا:

The object is not found.

این خطا به این معنی نیست که حتما حافظه سوخته است.

یکی از روش هایی که می توان امتحان کرد، مشخص کردن Offset است:

create partition primary offset=1024

اگر پیام زیر نمایش داده شد:

DiskPart succeeded in creating the specified partition.

یعنی پارتیشن با موفقیت ساخته شده است.

این روش در بعضی کارت های حافظه یا فلش هایی که بعد از clean رفتار عادی ندارند می تواند مشکل را حل کند.

8. فرمت کردن پارتیشن

بعد از ساخت پارتیشن، باید آن را Format کنیم.

ابتدا پارتیشن را انتخاب کنید:

select partition 1

سپس:

format fs=exfat quick

بعد از پایان Format:

assign

و در نهایت:

exit

حالا باید حافظه در This PC نمایش داده شود.

9. exFAT چیست و چرا از آن استفاده کنیم؟

یکی از فایل سیستم های مناسب حافظه های قابل حمل exFAT است.

مزایای exFAT:

  • مناسب برای فلش
  • مناسب برای کارت حافظه
  • پشتیبانی از فایل های بزرگ
  • مناسب برای فایل های چند گیگابایتی
  • محدودیت های قدیمی FAT32 را ندارد

برای مثال اگر بخواهید یک فایل 8GB را روی حافظه قرار دهید، FAT32 نمی تواند آن فایل را به صورت عادی ذخیره کند، اما exFAT برای چنین استفاده ای مناسب است.

البته سازگاری exFAT با بعضی گوشی ها، دوربین ها، کنسول ها و دستگاه های قدیمی ممکن است متفاوت باشد.

10. اگر گوشی کارت حافظه را نمی شناسد

اگر کارت حافظه در کامپیوتر شناسایی می شود ولی گوشی آن را نمی شناسد، چند مورد را بررسی کنید.

روش اول: کارت را دوباره جا بزنید

گوشی را خاموش کنید، کارت را خارج کنید و دوباره نصب کنید.

روش دوم: کارت را با کامپیوتر Format کنید

اگر گوشی از exFAT پشتیبانی می کند، می توانید از:

format fs=exfat quick

استفاده کنید.

اما اگر گوشی قدیمی است، ممکن است FAT32 گزینه سازگارتری باشد:

format fs=fat32 quick

توجه کنید که FAT32 برای فایل های بزرگ محدودیت دارد.

11. فلش یا مموری در This PC دیده نمی شود

ممکن است حافظه توسط ویندوز شناسایی شده باشد اما Drive Letter نداشته باشد.

مثلا در Disk Management می بینید:

Healthy
28 GB

اما در This PC چیزی وجود ندارد.

در این حالت می توانید یک Drive Letter اختصاص دهید.

در Disk Management:

  1. روی پارتیشن راست کلیک کنید.
  2. گزینه Change Drive Letter and Paths را انتخاب کنید.
  3. روی Add کلیک کنید.
  4. یک حرف مثل F انتخاب کنید.

حالا حافظه باید در This PC ظاهر شود.

12. حافظه به صورت Unallocated نمایش داده می شود

اگر در Disk Management چیزی شبیه این دیدید:

28 GB
Unallocated

یعنی پارتیشن قابل استفاده ای روی حافظه وجود ندارد.

اگر اطلاعات مهم نیست:

  1. روی فضای Unallocated راست کلیک کنید.
  2. New Simple Volume را انتخاب کنید.
  3. Next را بزنید.
  4. کل ظرفیت را انتخاب کنید.
  5. یک Drive Letter انتخاب کنید.
  6. فایل سیستم را انتخاب کنید.
  7. Format را انجام دهید.

برای یک حافظه قابل حمل جدید، exFAT معمولا گزینه مناسبی است.

13. خطای Write Protected یا Read Only

یکی از مشکلات رایج این است که ویندوز می گوید حافظه Write Protected است.

ابتدا DiskPart را باز کنید:

diskpart

سپس:

list disk

حافظه را انتخاب کنید:

select disk 3

و سپس:

attributes disk

اگر مقدار زیر را دیدید:

Read-only : Yes

این دستور را اجرا کنید:

attributes disk clear readonly

اگر موفقیت آمیز بود، دوباره:

attributes disk

را اجرا کنید و بررسی کنید که:

Read-only : No

باشد.

بعد می توانید دوباره عملیات پارتیشن بندی را انجام دهید.

14. اگر Card Reader مشکل داشته باشد

گاهی مشکل اصلا از کارت حافظه نیست.

Card Reader می تواند باعث شود:

  • کارت یک بار شناسایی شود و یک بار نشود
  • ظرفیت کارت اشتباه نمایش داده شود
  • کارت به صورت No Media نمایش داده شود
  • عملیات Format با خطا مواجه شود
  • عملیات Partition بندی شکست بخورد

بنابراین اگر کارت رفتار عجیبی دارد، حتما آن را با یک Card Reader دیگر امتحان کنید.

اگر microSD است، می توانید آن را:

  • با یک Card Reader دیگر
  • با آداپتور دیگر
  • یا مستقیما داخل گوشی

امتحان کنید.

15. معنی No Media چیست؟

اگر DiskPart چنین چیزی نشان دهد:

Disk 3    No Media    0 B

این حالت با RAW فرق دارد.

در RAW، ویندوز حافظه را با ظرفیت واقعی می بیند ولی فایل سیستم را نمی شناسد.

اما در:

No Media
0 B

ویندوز معمولا فقط دستگاه Reader را می بیند و نمی تواند حافظه واقعی داخل آن را در دسترس قرار دهد.

اگر این حالت با چند Reader مختلف تکرار شود، احتمال خرابی سخت افزاری کارت بسیار زیاد است.

16. اگر ظرفیت کارت درست نمایش داده نمی شود

مثلا کارت شما باید 32GB باشد ولی ویندوز آن را این طور نشان می دهد:

8 GB

یا:

0 B

یا:

No Media

ممکن است کارت خراب باشد.

همچنین کارت های حافظه تقلبی وجود دارند که ظرفیت واقعی آنها بسیار کمتر از ظرفیتی است که روی بسته بندی نوشته شده است.

17. اگر DiskPart می گوید No usable free extent

این خطا ممکن است بعد از clean دیده شود:

No usable free extent could be found.

اگر مطمئن هستید Disk درست را انتخاب کرده اید، ابتدا:

clean

را اجرا کنید.

سپس می توانید این روش را امتحان کنید:

create partition primary offset=1024

اگر موفق شد:

select partition 1
format fs=exfat quick
assign

اگر این روش هم جواب نداد، باید وضعیت سخت افزاری کارت و Reader بررسی شود.

18. اگر Create Partition با The object is not found مواجه شد

خطای:

The object is not found.

می تواند نشان دهد که Windows DiskPart نمی تواند یک پارتیشن قابل استفاده روی آن Media ایجاد کند.

در این حالت این موارد را بررسی کنید:

  1. کارت را جدا و دوباره وصل کنید.
  2. Card Reader دیگری امتحان کنید.
  3. کارت را در گوشی امتحان کنید.
  4. دوباره list disk بگیرید.
  5. مطمئن شوید ظرفیت درست نمایش داده می شود.

اگر یک بار کارت به صورت:

28 GB Online

و بار دیگر:

No Media 0 B

نمایش داده شود، احتمال مشکل سخت افزاری بیشتر می شود.

19. اگر Format خطا می دهد

اگر بعد از ساخت پارتیشن دستور زیر:

format fs=exfat quick

خطا داد، ابتدا بررسی کنید که پارتیشن را انتخاب کرده باشید:

select partition 1

بعد:

format fs=exfat quick

اگر هنوز خطا وجود داشت، متن کامل خطا را بررسی کنید.

خطاهای مختلف دلایل مختلفی دارند و نباید بدون توجه به پیام خطا، دستورات تصادفی اجرا کرد.

20. آیا CHKDSK می تواند مموری را تعمیر کند؟

دستور CHKDSK برای بررسی و تعمیر فایل سیستم مناسب است، اما فقط زمانی که فایل سیستم قابل شناسایی باشد.

مثلا اگر کارت شما Drive Letter F دارد:

chkdsk F: /f

اگر فایل سیستم RAW باشد، ممکن است CHKDSK نتواند آن را تعمیر کند.

در چنین شرایطی اگر اطلاعات مهم نیستند، معمولا بهتر است پارتیشن را از نو بسازید و Format کنید.

21. اگر فایل ها مهم هستند چه کنیم؟

اگر فایل های مهمی روی کارت یا فلش دارید، قبل از Format این کارها را انجام ندهید:

clean

یا:

format

یا:

create partition primary

چون این دستورات می توانند ساختار اطلاعات را تغییر دهند و بازیابی اطلاعات را سخت تر کنند.

در چنین شرایطی ابتدا باید سراغ Recovery بروید.

22. آیا Recovery می تواند باعث خراب شدن کارت شود؟

نرم افزارهای Recovery معمولا برای خواندن اطلاعات طراحی شده اند، اما عملیات ریکاوری می تواند فشار زیادی روی یک حافظه خراب وارد کند.

مخصوصا اگر حافظه از قبل مشکل سخت افزاری داشته باشد.

اگر بعد از Recovery کارت دیگر رفتار عادی ندارد، ابتدا Reader دیگری را امتحان کنید و وضعیت کارت را در Disk Management بررسی کنید.

23. اگر بعد از Recovery کارت Format نمی شود

اگر فایل ها دیگر مهم نیستند، می توانید کارت را کاملا از نو پارتیشن بندی کنید.

یک روش استاندارد:

diskpart
list disk
select disk 3
clean
create partition primary
select partition 1
format fs=exfat quick
assign
exit

اگر create partition primary خطا داد:

clean
create partition primary offset=1024

سپس:

select partition 1
format fs=exfat quick
assign

در صورت موفقیت، کارت دوباره قابل استفاده خواهد بود.

24. اگر ظرفیت کارت درست نمایش داده نمی شود

اگر کارت حافظه ظرفیت غیر عادی نشان می دهد، مثلا کارت 32GB به صورت 8GB یا 0GB نمایش داده می شود، ابتدا Reader دیگری را امتحان کنید.

اگر مشکل در چند دستگاه تکرار شد، احتمال خرابی سخت افزاری یا تقلبی بودن کارت وجود دارد.

برای کارت های مشکوک بهتر است ظرفیت واقعی حافظه با ابزارهای تست مخصوص بررسی شود.

25. اگر کارت بعد از Format دوباره خراب می شود

اگر کارت را Format می کنید اما بعد از مدتی دوباره:

  • RAW می شود
  • فایل ها خراب می شوند
  • فایل ها ناپدید می شوند
  • امکان نوشتن از بین می رود
  • ظرفیت اشتباه نمایش داده می شود

احتمال خرابی سخت افزاری بالاست.

در چنین شرایطی بهتر است به حافظه برای نگهداری اطلاعات مهم اعتماد نکنید.

26. بهترین فایل سیستم برای چه کاری است؟

کاربرد پیشنهاد
فلش معمولی exFAT
انتقال فایل های بزرگ exFAT
استفاده بین Windows و دستگاه های جدید exFAT
دستگاه های قدیمی FAT32
کارت حافظه دوربین طبق توصیه سازنده
کارت حافظه گوشی طبق پشتیبانی گوشی
فایل های بزرگ تر از 4GB exFAT

FAT32 یک محدودیت مهم دارد: یک فایل نمی تواند بزرگ تر از حدود 4GB باشد.

بنابراین اگر با فایل های بزرگ کار می کنید، exFAT معمولا انتخاب مناسب تری است.

27. روش سریع تعمیر فلش یا مموری که اطلاعاتش مهم نیست

اگر مطمئن هستید اطلاعات لازم نیستند و حافظه توسط ویندوز شناسایی شده است:

diskpart
list disk
select disk X
clean
create partition primary
select partition 1
format fs=exfat quick
assign
exit

به جای X شماره واقعی فلش یا کارت حافظه را قرار دهید.

اگر create partition primary خطا داد:

clean
create partition primary offset=1024

سپس:

select partition 1
format fs=exfat quick
assign
exit

28. مهم ترین نکته در استفاده از DiskPart

بزرگ ترین خطر DiskPart خود ابزار نیست؛ انتخاب Disk اشتباه است.

فرض کنید کامپیوتر شما این وضعیت را دارد:

Disk 0    465 GB
Disk 1    447 GB
Disk 2    232 GB
Disk 3     28 GB

اگر کارت حافظه 28GB است، احتمالا:

select disk 3

درست است.

اما اگر فلش 64GB باشد، نباید صرفا بر اساس شماره Disk آن را انتخاب کنید.

همیشه ظرفیت را با حافظه واقعی خود مقایسه کنید.

هرگز بدون بررسی از این دستور استفاده نکنید:

clean

29. نتیجه گیری

مشکل فلش، کارت حافظه و microSD همیشه به معنی سوختن حافظه نیست.

اگر ویندوز هنوز ظرفیت واقعی حافظه را تشخیص می دهد، معمولا ارزش دارد ابتدا فایل سیستم و پارتیشن بندی آن را بررسی کنیم.

در بسیاری از موارد می توان با DiskPart پارتیشن قبلی را پاک کرد و یک پارتیشن جدید ساخت:

clean
create partition primary

و سپس آن را Format کرد:

select partition 1
format fs=exfat quick
assign

اگر ایجاد پارتیشن با خطای No usable free extent مواجه شد، می توان در بعضی شرایط از:

create partition primary offset=1024

استفاده کرد.

اما اگر حافظه به صورت No Media و 0 B نمایش داده شود یا با چند Card Reader مختلف مرتب قطع و وصل شود، احتمال خرابی سخت افزاری بالاتر است و فرمت کردن دیگر راه حل اصلی نیست.

در نهایت همیشه این قانون را به خاطر داشته باشید:

اگر اطلاعات مهم هستند، اول Recovery و بعد تعمیر.

اگر اطلاعات مهم نیستند، می توان پارتیشن را پاک کرد و حافظه را از نو ساخت.
